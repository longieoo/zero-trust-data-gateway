# Recorded evidence

These artifacts were generated on 23 October 2026 using synthetic data. They are retained as historical evidence, not as a current CI status. The original verification receipt refers to the full pre-publication tree; the public repository omits delivery-only files and has edited documentation.

Machine names and local filesystem prefixes in exported text artifacts have been normalized for publication. Test counts and measured values have not been intentionally changed. Browser captures use a real client certificate with the local server CA warning ignored; the separate Python HTTPS checks verify the CA and hostname.

`benchmark.json` and `benchmark-samples.csv` are the final recorded run. Files containing `before` are tuning/security baselines, not alternative current releases. Dependency audit results are time-specific. Audit snapshots, session databases, private keys and credentials are not included.
